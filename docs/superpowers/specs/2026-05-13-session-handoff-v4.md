### 3.3 Window startup flow

```
main.py:
  init_db(DB_PATH)
  app = HRApp()           # tk root, hidden via withdraw()
  splash = SplashScreen(parent=app)
  app.after(2000, _reveal)
  app.mainloop()

_reveal():
  splash.destroy()
  app.deiconify()
  app.state("zoomed")     # maximize with title bar visible
```

  Brand magenta `#EC4899` is hardcoded as `BRAND_MAGENTA` in places where the brand link matters (months.py active card, app.py sidebar Solution + active month line, splash.py).

## 5. Workflow Rules (preserved)

1. **NO auto-push.** User explicitly authorizes each push. The harness will block `git push origin ... :implement-mvp` (default branch). Pushing to `v1/v2/v3/v4` snapshot branches is OK when user says "push".
2. **Push timeout fallback.** If push hangs on SSH passphrase, just commit locally and continue. User says: "lanjutkan proses" — don't block on push.
3. **.exe may be running.** If `pyinstaller --clean` hits `PermissionError` or deploy `mv _internal` fails: ask user to close the app, then retry.
4. **Test before commit.** `../../../.venv/Scripts/python.exe -m pytest -q` should show 97 passed. If less, find what regressed.
5. **Deploy with rotation.** Backup `.exe → .exe.bak`, `_internal → _internal.bak`, rotate `.bak → .bak.old`, drop `.bak.old` first. Preserves 2 levels of rollback. `data/hr.db` NEVER touched.
6. **Mulai Bulan Baru button is GONE.** Don't reintroduce. Multi-month means data is preserved; user picks active month via Riwayat Bulan or auto-detect on import.
7. **`reset_month()` function kept as dead code** in `src/db/attendance.py` for potential future use (commented as such).
8. **Brand: Hybrid A approach.** Don't overhaul to black/magenta theme. Brand magenta only at entry signature points (splash, icon, sidebar accents, active month). App theme remains purple/orange/gold.
